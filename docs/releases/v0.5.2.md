# Tote 0.5.2

Fixes the desktop update screen continuing to say “No newer stable release” after a new release has been published.

## What changed

- **Check for updates** now fetches fresh GitHub release information on every deliberate check, instead of reusing a result for fifteen minutes.
- **Download update** also refreshes release information before selecting a package.
- Concurrent requests still share one fetch. A failed explicit refresh reports an error instead of presenting an older cached result as a successful check.
- Includes the DSH local-web authentication fix from 0.5.1.

## Upgrade

Linux AppImage users can update from **Settings → About → Check for updates → Download → Install**. The background host and its agent sessions remain running while the desktop viewer reopens. If an older viewer still reports an earlier release, its existing cache expires after fifteen minutes; saving drafts and reopening the viewer also clears that cache. This patch removes that wait for subsequent manual checks.

In-app desktop installation requires a writable AppImage. Package-managed installations remain outside that installation path. Android uses its existing in-app update flow and advances to versionCode 14 with unchanged production signing identity and lineage. There are no Android behavior changes in this patch. Android 13+ and wire protocol v1 requirements are unchanged.

## Verification

Regression checks cover immediate discovery after a cached no-update result, shared concurrent refreshes, failed-refresh reporting, and downloads after a new release appears. A real Electron renderer test clicks **Check for updates** twice through the production preload and main-process handlers and verifies that the second click immediately discovers the newer fixture release.

Release validation and packaging also exercise desktop/mobile regressions, packaged PTYs, background-host reconnect and Android signing. The release includes package hashes and the production update manifest. These automated checks do not claim a new physical Android installation test.
