# Tote 0.4.0 — desktop + Android

Use the terminals on your computer from your phone. This release adds the Tote Android companion, Tailscale device discovery, a workspace/group side panel and readable phone-width terminal output.

## Downloads

- **Linux x64:** `Tote-0.4.0.AppImage`, `tote_0.4.0_amd64.deb`, or `tote-0.4.0.pacman`.
- **Android:** `tote-android-0.4.0.apk`.
- **Verification:** `SHA256SUMS` covers all four installers.

The Android APK is a **debug-signed preview**, not a Play Store release. It uses the same application identity and signing certificate as the earlier Tote test APKs so it can be installed as an update. macOS and Windows installers are not included in this release; source build instructions are in the README.

## What’s new

- A side panel for workspaces, nested groups and terminals replaces Android selection popups.
- Terminal text wraps to the phone’s width at a readable size. This changes only the phone view; desktop terminal dimensions remain unchanged. Turn off **Wrap text** for the original terminal grid.
- Voice input records into an editable draft. Stop, review and send separately.
- Live terminal replay, reconnect, per-session drafts and read-only file previews.
- Desktop discovery uses Tailscale directly, including wired PCs and phones outside the home network. Directory hints let updated hosts introduce older reachable Tote computers.

## Fixes

- Fixed a terminal-response filter import that stalled rendering and disabled navigation when rich terminal applications emitted device queries.
- Fixed races between workspace changes and selection of unavailable saved terminals.
- Prevented output from a previous terminal appearing after switching sessions.

## Connect

1. Update desktop Tote and enable **Share device**.
2. Connect Tailscale on your computer and phone using the same owner account.
3. Install the Android APK, open Tote and select your computer.
4. Use the ☰ side panel to choose a workspace, group and terminal.

Existing computer sessions continue when the phone disconnects. The Android app is a client; files and terminal processes stay on the computer. This release does not add Android web-provider tabs, file editing/transfers, PDF previews or background recording.

## Validation

Desktop/protocol tests, mobile UI regressions, Android unit tests and lint passed. The installed APK was also tested in an Android emulator against the actual main PC, with real taps, live input/output, workspace and group switching, and reconnection. Phone-only wrapping was checked without resizing host sessions.
