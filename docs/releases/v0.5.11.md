# Tote 0.5.11

Each remote DSH pane now opens its own browser view on the computer running DSH. The page reflows to fit the viewing pane. Each view has its own scrolling and browser storage for drafts. The views use the same DSH backend and can reuse its signed-in session.

Keep a Tote window open on the source computer. The source and viewing apps both need the new viewer code. A running 0.5.10 background host can carry these requests while its terminal sessions continue. After ten minutes without a request, Tote closes an idle remote DSH view and clears its temporary browser storage.

Production updater targets are Linux and Android. macOS builds are available through the project's preview pipeline.
