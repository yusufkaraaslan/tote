# Tote 0.5.9

Choose **View read-only** from a desktop terminal’s heading menu or the Android workspace tools to follow output without sending input, resizing the terminal or stopping its agent. The host enforces this choice per viewer and terminal. Select **Take control** to enable input and take over sizing. Other viewers see who controls the grid. Interactive desktop viewers can still claim sizing by focusing a terminal, and Android resizes only when requested.

The release also updates Electron to 45.4.1 and the Android build to Gradle 9.9.2.

Install viewer updates through **Settings → About** on Linux or **Updates** on Android. Read-only controls become available once the computer serving the terminal runs the updated host. Finish live sessions before explicitly upgrading that host.
