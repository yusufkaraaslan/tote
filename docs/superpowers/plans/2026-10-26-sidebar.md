# Sidebar implementation plan

**Goal:** Apply the approved `concepts/sidebar.html` layout to the real app.
**Architecture:** Retain existing control IDs and handlers. Nest the group controls after the active workspace row, keeping all pane elements in their existing tiling surface. Keep collapsed state local to the viewer.
**Tech stack:** Electron, vanilla HTML/CSS/JS.
**Spec:** User-approved `concepts/sidebar.html`.

## Constraints and review focus
- Never reparent webviews or terminal panes; only navigation controls move.
- Vertical overflow, active-row reveal, and drag scrolling must work with many spaces.
- Compact mode must retain groups, device switching, temporary/remote creation, and settings.
- Sidebar menus must stay on screen and above panes.
- Collapsing must trigger the existing tiling ResizeObserver and refit terminals.
