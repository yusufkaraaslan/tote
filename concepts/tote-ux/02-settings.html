02 — settings

  • Nav on the left, one page of content — no tabs-inside-modals. Everything fits without scrolling sideways in your head.
  • Devices is first-class because the multi-machine story is tote's bet. The Tailscale card shows its real state machine — click through it.
  • States, not screens: install → open → connect → devices list all live in one card; the card mutates instead of navigating.
  • Everything is resumable: first-run setup maps 1:1 onto these sections, so "finish later in settings" is literally true.
  • Question it tests: which of these deserve nav slots — should providers/agents live under one "services" page? is behavior too sparse?
