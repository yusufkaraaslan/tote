DEVICES

Your other machines, reachable inside tote. Tailscale decides who is "you" — only devices on your own tailscale account can connect; a shared-in node is refused.

tailscalechecking…
looking for the tailscale daemon…

Remote spaces ride this: +r on the strip makes a space that lives on another machine over ssh/Tailscale. Re-auth is ambient — a banner in the files pane, never a modal.

SPACES

Workspaces are the folders tote organizes everything around. One global space plus your projects; ids are stable across renames.

WEB PROVIDERS

The +web menu on the strip. Each opens in its own session partition, so logins never leak between providers.

CLI AGENTS

Agent terminals on +term and ctrl+`. Each profile carries its install command — the setup wizard uses it.

NATIVE APPS

Desktop LLM apps tote can launch into the active workspace. macOS can also bridge their Downloads into the space's inbox (behavior).

BEHAVIOR

Defaults for downloads. Sharing and keep-awake are device settings — see devices.
