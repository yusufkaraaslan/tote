Concept A — Terminal Native

  • Idea: Tote is already 80% terminal. Stop dressing it as a web app; adopt tmux/vim grammar.
  • One accent color, monospace everywhere, zero rounded corners — chrome disappears, content is the UI.
  • Panes numbered like tmux windows; the keyline teaches the binds that already exist.
  • Strip + groups collapse into a single 30px status line.
  • Question it tests: is maximal density + keyboard grammar freeing, or hostile to new users?
