# Tote 0.5.8

Adds terminal closing on Android and hides the desktop menu bar by default.

## What changed

- Android now has a **×** button beside the terminal title and **Close terminal** in the workspace tools menu. Closing a running terminal asks for confirmation because it stops the shared session and its agent for every viewer.
- Closed terminals disappear from phone navigation without rewriting desktop layouts. Ended or unavailable terminal panes can also be dismissed. Unsent drafts remain available under **Updates → Review unsent drafts**.
- Closing targets the selected session and device even if navigation changes before the host replies. Duplicate taps are blocked; reconnect never retries a close. Failed or uncertain requests keep the pane available and report the error.
- Linux and Windows hide the File/Edit/View menu bar by default. Keyboard shortcuts remain available, and Alt can reveal the menu. The macOS application menu is unchanged.

## Upgrade

After the stable release is published, use **Settings → About → Check for updates → Download → Install** on Linux AppImage, or **Updates → Check for updates → Download → Install** on Android. Android versionCode is 20. The existing background host and other terminal sessions stay running; these viewer changes do not require a host restart. Wire protocol v1 is unchanged.

## Verification

Mobile renderer coverage checks cancellation, successful closing, host errors, duplicate taps, navigation while a close is pending, offline controls, reconnect without retry, ended-pane dismissal, draft retention, and absence of desktop layout writes. The background-host renderer fixture checks that the desktop menu stays hidden when opening and reopening a viewer while terminal sessions survive.

Physical Android touch/confirmation and signed installed-app upgrade checks remain release verification steps.
