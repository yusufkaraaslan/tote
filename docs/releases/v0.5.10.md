# Tote 0.5.10

Desktop and Android viewers can use the selected computer’s live web panes, including DSH, cloud providers and custom providers. Selecting a pane shows its current page and login. Click or tap a field to type, scroll with the wheel or a swipe, and use Enter to submit. Pages and OAuth popups run in the computer’s Tote browser. On Android, a separately entered web address still opens in the phone browser.

Install through **Settings → About → Check for updates → Download → Install** on Linux, or **Updates** on Android. Web sharing requires the updated background host and an open Tote desktop window on the computer serving the panes. Finish running agents before explicitly upgrading that host. DSH can keep listening on loopback.
