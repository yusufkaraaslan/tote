Tote itself needs Node.js and npm (also used to install CLI agents), git for project spaces, and a working terminal layer.

Install the agents you want. Each install runs live in the terminal below — watch it, skip it, or re-run later from this wizard.

For any other MCP-capable app (Cursor, Cherry Studio, Kimi Code via /mcp-config…), paste this snippet into its MCP config to mount the active workspace:

Your spaces. Global is the default; add one space per project. The active space receives all downloads and is where new terminals start.

All set. Typical flow: pick a space → research in a web tab → download (lands in the space's inbox) → resume in a CLI terminal (claude -c / kimi -C continue their last session).
