# Tote 0.5.3

Updates the desktop runtime, shared terminals, workspace watcher and Android toolchain while preserving running background-host sessions during viewer updates.

## What changed

- Electron 45.3.4 fixes a memory leak involving removed elements that had been right-clicked.
- Desktop, host and Android use xterm 6 together. Terminal scrolling, hidden-pane recovery, colors and passive-viewer dimensions retain their existing behavior.
- Chokidar 6 retains workspace watcher budgets, Unity cache exclusions and awaited watcher replacement. Development and standalone hosts now require Node 22.22+.
- Android uses AGP 9.5.1, Gradle 9.9.1, compile SDK 37 and OkHttp 5.5.1. Minimum Android 13/API 33 and target API 36 remain unchanged.
- Packaging uses patched minimatch 11 for affected modern consumers, retaining older APIs needed by ASAR tooling. Packaged checks reject accidental inclusion of advisory-bearing build tools.

## Upgrade

Use **Settings → About → Check for updates → Download → Install** on Linux AppImage, or the existing Android in-app updater. The desktop viewer reconnects to the same running background host; active terminals are not restarted. Upgrade the host separately only after its sessions finish. Android advances to versionCode 15 with the same production signing identity and lineage. Wire protocol v1 is unchanged.

## Verification and known limits

The release pipeline checks Linux/macOS/Windows unit tests and preview packages, real desktop/mobile renderers, packaged PTYs and copied-host replacement, Android native tests/lint, signing identity and artifact hashes. Separate fixtures exercised xterm 5/6 host/viewer interoperability and preserved a real shell across viewer quit/crash/relaunch.

The remaining picomatch advisory has no patched upstream release as of 2026-11-18. It is reachable through build tooling; Tote's node-gyp calls use fixed `build/*.sln` and `build/*.mk` patterns. These tools are excluded from the packaged application. The full dependency audit continues to report the finding; this release does not claim a clean audit. See [dependency decisions](../dependencies.md).

Physical phone testing is deferred at the maintainer's request. Emulator and automated results do not establish phone-specific Tailscale, voice or save-permission behavior. The final release verification record must distinguish those limits from signed artifact and upgrade checks.
